## Alasan pilihan (kriteria juri, paling penting dulu)
1. **Joke satu baris yang utuh + punchline nyata:** ketiganya lolos, tapi A punya
   punchline paling tajam — "forgot password link is now my homepage" membalik
   ekspektasi di kata terakhir.
2. **Kejutan di pandangan pertama:** A paling tak terduga — setup soal password
   kuat mengarah ke pujian diri, lalu berbalik jadi pengakuan kalah sama sistem
   sendiri. B (crown → kingdom) adalah wordplay yang langsung ketebak dari kata
   "crown"; C ("took me down" / "listened") wordplay-nya juga ide pertama.
3. **Ekonomis:** A 93 karakter, tiap kata bekerja; tidak ada kata mati.
4. **Suara khas / sudut pandang sendiri:** A bicara dari pengalaman universal
   yang spesifik (semua orang pernah kalah sama password sendiri) tanpa jadi
   klise generik. B dan C lebih terasa seperti joke template.
5. **Tahan dibaca ulang:** A tetap lucu karena ironinya nyata, bukan cuma
   kejutan sekali pakai.
